# Pubblicare Registro con GitHub Pages

## Aggiornare i file esistenti (il tuo caso)

1. Vai sul repository GitHub del tuo sito.
2. Per ciascuno dei tre file (`index.html`, `sw.js`, `manifest.json`): apri il file → icona della matita (Edit) oppure **Add file → Upload files** per sostituirlo.
3. **Commit changes**.
4. GitHub Pages si aggiorna da solo in un paio di minuti.
5. Chiudi del tutto la scheda del browser (o l'app se l'hai sulla Home) e riapri — non basta ricaricare.

## Da zero (se dovessi mai ripartire)

1. [github.com](https://github.com) → **+** → **New repository** → nome, es. `registro` → Public → Create.
2. Nel repository → **Add file → Upload files** → trascina `index.html`, `sw.js`, `manifest.json` (alla radice) → Commit.
3. **Settings** (del repository) → **Pages** (menu a sinistra) → **Source: Deploy from a branch** → **Branch: main / (root)** → **Save**.
4. Dopo un paio di minuti, in cima alla stessa pagina compare il link: `https://tuonome.github.io/registro/`

## Installarla sul telefono

Apri il link da Safari su iPhone → **Condividi → Aggiungi a Home**.
